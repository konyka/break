## Upstream anchors (verified from ref f80a541 = v1.21.4 release commit, fetched fresh 2026-08-30)

- **GRL grammar** (`src/parser/grl/stream_syntax.rs`): `var: EventType from stream("name") over window(<digits> <unit>, sliding|tumbling)`; event type optional (`e: from stream("events")` legal; a leading `from` is not consumed as a type, :216); window clause optional (:93 `opt(parse_window_spec)`); stream name = chars up to next `"`; duration = `digit1` + `multispace1` + `alpha1`, units case-sensitive (:166-179): `ms|millisecond|milliseconds` → ms, `sec|second|seconds` → s, `min|minute|minutes` → ×60s, `hour|hours` → ×3600s, anything else parse error; window type only `sliding|tumbling` (:192) — `session` is a GRL parse error upstream (WindowType::Session exists in the Rust enum but is unreachable from GRL). Join grammar `pattern && pattern` exists (:429) but `join_conditions` is always empty and nothing consumes `StreamJoinPattern` — vapor; local: parse error, documented.
- **Windows** (`src/streaming/window.rs`): bounds `[start, end)`; tumbling bucket = `ts / window_ms * window_ms`; WindowManager sliding/session windows start at the event's own timestamp (`calculate_window_start` :279-289); `is_expired(current_time)`; `record()` trailing-window counter. Local windows already implement all three kinds with retention bounds, event-time recording watermark, and DROP/ACCEPT/ERROR late policy (extensions.c:285-318, tumbling_session.c:74-90) — the C delta is watermark-driven CLOSURE only.
- **Watermark** (`src/streaming/watermark.rs`): `is_late(event_time) = event_time < watermark.timestamp` (:43); strategies `Periodic{interval}` (processing-time — not applicable single-threaded, document), `BoundedOutOfOrder{max_delay}` → `wm = max_ts - delay` emitted only if advancing (:131), `MonotonicAscending` → wm = max observed ts; `LateDataStrategy` {Drop, AllowedLateness{max}, SideOutput, RecomputeWindows} with `lateness = wm - event_ts` and `lateness <= max → Process else Drop` (:236-247); late events never advance the watermark (:340 on-time branch only). Upstream watermarks never drive window closure except join-node eviction — the closure wiring is a documented local composition.
- **Joins** (`src/rete/stream_join_node.rs`): `JoinType {Inner, LeftOuter, RightOuter, FullOuter}` (:11); `JoinStrategy {TimeWindow{duration}, CountWindow{count}, SessionWindow{gap}}` (:24); per-key buffers `HashMap<String, VecDeque<StreamEvent>>`; inner matches emit immediately; outer-join unmatched emissions fire on `update_watermark` (:204); `JoinedEvent {left: Option, right: Option, join_timestamp}` (:35). Routed by `event.metadata.source` via `StreamJoinManager`. NOT connected to StreamRuleEngine upstream.
- **Aggregation kinds** (`src/streaming/aggregator.rs`): enum `AggregationType {Count, Sum{field}, Average{field}, Min{field}, Max{field}, CountDistinct{field}, StdDev{field}, Percentile{field, percentile}, First, Last, CountBy{field}}` (:12). StdDev = POPULATION (variance = Σ(v-mean)²/N, :233), requires ≥2 values else `None`. Percentile: 0-100 scale, sorted ascending, nearest-rank `index = round(p/100 × (len-1))` (:253). CountDistinct = distinct `format!("{:?}")` strings — local mapping: distinct typed values (typed equality over re_value_t), documented.
- **StreamAnalytics** (`src/streaming/aggregator.rs:285`): `cache: HashMap<String,(u64,AggregationResult)>` + `cache_ttl` ms; hit iff `current_time - ts < ttl` (:311); on miss recompute+insert, then evict the WHOLE cache by TTL (:323). `moving_average(windows, field, window_count)` (:329): last N windows, `sum(all events' field)/count(events)` — global event average, NOT an average of per-window averages; `None` if no windows/events. `detect_anomalies(windows, field, threshold)` (:357): needs ≥3 windows and ≥10 historical values (all windows except the last); population mean/stddev over historical; flags events in the LAST window with `|z| > threshold`; returns event IDs. `calculate_trend(windows, field)` (:399): needs ≥2 windows; per-window averages; half-split; `change_percent = (second_avg - first_avg)/first_avg × 100`; `> +5` Increasing, `< -5` Decreasing, else Stable (:416); `TrendDirection {Increasing, Decreasing, Stable}` (:430).
- **Fact injection** (`src/streaming/engine.rs:341-378`): at `execute_rules()`, for EACH active window: fresh `Facts`, inject `WindowEventCount` (count as f64), `WindowStartTime`, `WindowEndTime`, `WindowDurationMs` (:347-353); auto-detect numeric fields by scanning all events' data maps (`detect_numeric_fields` :383); per field inject `{field}Sum`, `{field}Average`, `{field}Min`, `{field}Max` (field name verbatim + capitalized suffix, :364-376); run the WHOLE rule base synchronously per window; actions not captured (empty, admitted :304-306). Pinned usage: rule `when WindowEventCount > 5` (:478-481).
- **Topology** (`src/streaming/engine.rs:183-262`): tokio mpsc channel + `Arc<RwLock<WindowManager>>` + batch task — documented as NOT APPLICABLE (local engine stays single-threaded per the rule_engine.h:452-463 threading contract).

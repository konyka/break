# Audio: automatic gain control for captured voice

Status: Done

## Goal

`audio_capture` delivers 16-bit frames at whatever level the microphone
gives. Add an automatic gain control (AGC) the owner thread runs on those
frames before `break_voice_encode*`, so quiet and loud talkers reach a
similar level without clipping.

## API (`engine/src/audio/audio_agc.h`)

- `AudioAgcConfig { sample_rate, channels, target_dbfs, max_gain_db,
  attack_ms, release_ms, gate_dbfs }`.
  Ranges: rate 8000..192000, 1 or 2 channels, target -60..0 dBFS,
  max gain 0..60 dB, attack 0.1..1000 ms, release 1..10000 ms,
  gate -120..0 dBFS and below the target. INVALID otherwise.
- `audio_agc_init(agc, config)`: gain 0 dB, empty level detector.
- `audio_agc_process_i16(agc, samples, frames)`: in place.
- `audio_agc_gain_db(agc)`.

## Behaviour

- Level: one-pole mean square over 10 ms of the channel average of x^2
  (x in [-1, 1)), in dBFS as 10 log10.
- Desired gain = target - level, limited to [-max_gain_db, max_gain_db].
  Below the gate the gain holds, so silence and room noise are not boosted.
- The gain moves towards the desired gain with the attack time constant
  when it falls and the release time constant when it rises, once per
  frame, the same gain on every channel.
- Output: round(x * gain), clamped to the i16 range.
- Frame by frame, so the chunking of the calls does not change the output.

## Tests (`test_audio_agc`)

1. Config validation, including gate >= target.
2. A quiet sine settles at the target (within 1 dB), a loud one too.
3. The maximum gain caps a very quiet sine.
4. Below the gate the gain holds and the output equals the input.
5. A burst after quiet never wraps (clamped to the i16 range).
6. Stereo: one gain for both channels, the ratio between them kept.
7. Chunks of 1, 7 and 480 frames give the same output.

## Result

- `test_audio_agc` 8/8. Mutation: 20 of 23 killed at first (rounding,
  left-only level, level window); an independent reference model test
  kills all 23. ASan+UBSan clean; `-Wshadow -Wdouble-promotion` clean.
- The gain is kept in double: near the settled value the per-frame step
  is below an f32 ulp.

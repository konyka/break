# X11 完全移除实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从当前主分支完全移除 X11 后端、依赖和专属测试，在原生 Wayland 上保留并验证 Vulkan 默认与 OpenGL 最后降级，再直接推送远程主分支。

**Architecture:** Linux 只保留原生 Wayland 窗口路径；公共 Platform/RHI 接口继续服务 Win32、Cocoa、移动端和 QNX。通用 GPU 行为测试迁移到 Wayland，X11 专属实现与测试删除，配置层对旧选项 fail closed。

**Tech Stack:** C11、仓库现有 C++20 公共 API 合同、CMake/CTest、Wayland/EGL、Vulkan、OpenGL、GitHub Actions、Weston。

## Global Constraints

- 实施只在 `.worktrees/remove-x11` 的 `remove-x11` 分支进行；每个任务独立提交、独立规格+质量评审，不创建 PR，不纳入暂停的 P12 修改。
- 用户明确选择完全移除，不保留 X11 弃用层。Linux 唯一窗口后端是原生 Wayland；Vulkan 默认，OpenGL 只作最后降级与画面对照。
- 删除 `window_x11.c`、`x11_touch.c/.h`、myui X11 PAL、Xlib surface、GLX 与 X11 专属测试/CI 路径；负向迁移合同中的 `x11` 字符串只用于拒绝旧配置和防止回潮。
- 不误删 Wayland、EGL/WGL、Win32/Cocoa/Android/iOS/QNX、公共 OpenGL loader、通用键码、evdev、EDID 或其他共享能力。其余 WSI 枚举数值保持稳定。
- `ENGINE_ENABLE_WAYLAND=OFF` 与 `MYUI_PAL=x11` 在 Linux 必须明确 configure 失败；缺 Wayland 开发依赖不得回退 X11 或 dummy。myui dummy 仅保留给独立 CPU/headless 测试。
- 所有新测试先取得实际行为 RED，再最小实现到 GREEN；每个任务至少一个生产行为变异被测试杀死后恢复。构建统一 `-j3`。
- record/headless/dummy 不能冒充真实窗口/GPU 证据；图形测试必须记录实际 backend/device，并区分 PASS 与 UNAVAILABLE。
- 历史文档不改写；当前文档明确 X11 已移除。主版本升级为 2.0.0，不创建发布 tag。
- 远程 `origin/master` 已包含 C++20 与 QUIC 更新，必须先合并并保留双方功能；不得用旧基线覆盖远程新实现。
- 后续 P12 命名不使用 `cry/Cry/CRY`，也不机械替换为 `break/Break/BREAK`；该迁移属于恢复 P12 后的独立任务，不在本移除计划混入无关重命名。

# Editor 乱码修复与 I18N 实施计划

> 设计：`docs/superpowers/specs/2026-10-27-editor-i18n-design.md`。分支 `sdd/editor-i18n`（基于本地 master `0aedc907`）。每个任务先写失败测试（RED），再实现（GREEN），任务结束提交。

## Global Constraints

- C11；不新增依赖。fontconfig 为可选：CMake 用 `pkg_check_modules(... IMPORTED_TARGET fontconfig)` 检测，找不到时编译为纯路径表实现。
- 翻译 key 为枚举；每种语言每个 key 必须有非空、合法 UTF-8 的文本。
- 语言状态是 shell 线程专用的进程级单值；不加锁。
- myui 只改一处：位图字体回退时 `LOG_WARN`。
- 不翻译引擎日志、远程协议、实体名、文件名。
- 默认语言由 `--lang` > `BREAK_LANG` > `LC_ALL` > `LC_MESSAGES` > `LANG` 决定，都无效时 `en-US`。
- 推送：只推 `sdd/editor-i18n` 并开 PR，不 force push，不动远端 master（远端已分叉 255/156）。

## Task 1：`break_editor_i18n` 核心（纯 CPU）

文件：新增 `engine/src/editor/editor_i18n.{h,c}`、`engine/src/editor/editor_i18n_tables.c`、`engine/tests/test_editor_i18n.c`；修改 `engine/CMakeLists.txt`（`break_editor` 与 `break_editor_test` 加入两个 TU，新增 `test_editor_i18n`）、`engine/tests/test_break_editor_target_contract.cmake`（源列表）。

接口：

```c
typedef enum { BREAK_EDITOR_LANG_EN_US = 0, BREAK_EDITOR_LANG_ZH_CN,
               BREAK_EDITOR_LANG_COUNT } BreakEditorLang;
typedef enum { BREAK_EDITOR_TR_... , BREAK_EDITOR_TR_COUNT } BreakEditorTr;
const char *break_editor_tr(BreakEditorTr key);           /* never NULL */
const char *break_editor_tr_lang(BreakEditorLang, BreakEditorTr);
bool break_editor_i18n_set_lang(BreakEditorLang lang);
BreakEditorLang break_editor_i18n_lang(void);
bool break_editor_i18n_parse_lang(const char *tag, BreakEditorLang *out);
BreakEditorLang break_editor_i18n_lang_from_env(void);
const char *break_editor_i18n_lang_tag(BreakEditorLang);  /* "en-US"/"zh-CN" */
const char *break_editor_i18n_lang_name(BreakEditorLang); /* "English"/"中文" */
```

RED 测试：每语言每 key 非空 + UTF-8 合法 + zh 与 en 不同（数字/符号类 key 列入白名单）；越界 key/lang 返回 key 名回退；`parse_lang` 覆盖 `zh-CN`/`zh_CN.UTF-8`/`ZH`/`zh-Hans`/`en`/`en_US.utf8`/`C`/`POSIX`/空/NULL/`fr`；`lang_from_env` 优先级（`setenv` 测试内恢复）；每个格式 key 的 `%` 规格在两种语言中序列一致。

## Task 2：editor 文本接入与运行时切换

文件：`engine/apps/editor/editor_panels.{c,h}`、`editor_panel_*.c`、`editor_hot_reload.c`、`editor_shader_reload.c`（日志行）、`engine/tests/test_editor_shell.c`。

# 原生 D3D12 RHI 后端实施计划（计划 D）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `engine/src/rhi/rhi_d3d12.c/h`（当前仅编入 WIN32-only 测试 `test_d3d12_native_failure`）晋升为编译期可选的真实 D3D12 后端 `engine_rhi_d3d12`，使 Windows × D3D12 组合在证据台账中从 HEADLESS 逐级升至 GPU-runtime，并完成 SDK 锁定、shader 管线、DXR、CI（windows-d3d12 / proton-d3d12）与文档收尾。

**Architecture:** 遵循设计规格 `docs/superpowers/specs/2026-10-14-multi-backend-rhi-design.md` §4.1：编译期单后端、独立静态库。`engine` 核心库只含 `RHI_CORE_SOURCES`（engine/CMakeLists.txt:238-243），`engine_rhi_d3d12` 静态库导出全部 `rhi_*` 符号，可执行 target 经计划 A 交付的 `engine_link_rhi_backend(<target>)` helper 链接恰好一个后端库。设备/队列/fence/descriptor heap 复用 `rhi_d3d12.c` 现有的 COM C 接口上下文（`RHI_D3D12Context`，rhi_d3d12.h:24-43），swapchain 走 IDXGISwapChain3/4 flip model，shader 走 vendored dxc（engine/external/VulkanSDK/Bin/dxc.exe）离线编译 DXIL。

**Tech Stack:** C11（CMake `project(PureCEngine LANGUAGES C)`，engine/CMakeLists.txt:2）、COM C 接口（COBJMACROS）、D3D12 + DXGI 1.6 + DRED 1.x + DXR（ID3D12Device5）、dxc → DXIL（SM 6.0）、CMake ≥3.20 + Ninja / Visual Studio 18 2026、CTest（SKIP_RETURN_CODE 77 约定）。

## Global Constraints

- **C11 纯 C**：后端保持 C 文件 `engine/src/rhi/rhi_d3d12.c`，**不新建 `rhi_d3d12.cpp`**。这是对用户方案中「rhi_d3d12.cpp」的有据偏离，理由：(1) 仓库 `project(PureCEngine LANGUAGES C)`（engine/CMakeLists.txt:2），唯一 C++ 是 `STREAMLINE_ROOT` 可选适配器（engine/CMakeLists.txt:332-344）且以 `enable_language(CXX)` 显式隔离；(2) MSVC 前端强制 `/W4 /WX` + `/TC`（engine/CMakeLists.txt:96-104），GNU/Clang 强制 `-Wall -Wextra -Werror -pedantic`（engine/CMakeLists.txt:105-115）；(3) 现有 `rhi_d3d12.c`（304 行）已用 COBJMACROS C 接口完整覆盖 device/queue/descriptor heap/fence/committed resource/barrier/submit，证明无需 C++。唯一的 `enable_language(CXX)` 前例属第三方 SDK 强制，本后端无此需求。
- **-Werror 零容忍**：MSVC `/W4 /WX`、Clang `/clang:-Werror`、GNU `-Werror -pedantic` 下零告警；Windows SDK 头触发的已知告警只允许沿用 engine/CMakeLists.txt:2084-2086 既有的 `/clang:-Wno-*` 豁免清单，不得新增。
- **TDD**：每个 Task 先写失败测试 → 运行确认失败（记录命令与预期输出）→ 最小实现 → 运行确认通过 → commit。CMake 脚本契约测试（`cmake -P`）与 `SKIP_RETURN_CODE 77` 是仓库既定 gate 惯例（规格 §3.7）。
- **证据等级纪律**：等级模型 `NONE → COMPILED → HEADLESS → NATIVE_SURFACE → GPU_RUNTIME → BENCHMARK_COMPARABLE`（engine/src/platform/platform_compat.h:49-56；规格 §2）。**Proton 仅作兼容验证 lane，其收据永远不计入 Windows 原生 D3D12 证据**；**禁止 D3D11On12 作为最终 RHI**；**禁止用 OpenGL wrapper 冒充 D3D12**。编译成功不等于 GPU-runtime；WARP（软渲染）证据只计 GPU-runtime 的下限收据并必须标注 `gpu=WARP`。
- **缺失 SDK → UNAVAILABLE + SKIP 77**：任何机器缺 Windows SDK / Agility SDK / dxc 时，gate 输出 UNAVAILABLE 并以退出码 77 跳过（沿用 engine/tests/test_d3d12_dependency_gate.cmake:5-8 与 :54-65 的既有模式），**不得降级、不得伪造证据**。
- **冻结文件清单（任何步骤不得修改/删除/移动）**：`.scratch-vkprobe/`、`engine/profile_trace.json`、`.tmp/`、仓库根 `d3d12_shader_gate.hlsl` 与 `d3d12_shader_gate.dxil`、`.env`、SSH 私钥（规格 §3.9、§9）。
- **前置条件**：计划 A 已完成——`engine_rhi_vulkan` / `engine_rhi_opengl` / `engine_rhi_headless` 独立静态库与 `engine_link_rhi_backend()` helper 已落地；`RHINativeHandleType` 已含 `RHI_NATIVE_HANDLE_D3D12 = 3`；`engine/tests/test_rhi_backend_internal_contract.cmake` 已重写为所有权断言；`engine/tests/test_rhi_backend_selection.cmake` 当前断言 d3d12 → FATAL_ERROR。若前置检查发现任一不成立，停止并先补齐计划 A，不得在本计划内偷偷重做。
- **错误模型**：不新增 `RHIResult` 枚举值（rhi.h:338-349；规格 §4.2），全部经既有值映射并由契约测试固定。

```cmake
# Asserts the D3D12 SDK pins recorded in agility_sdk_lock.txt.
set(LOCK_FILE "${CMAKE_CURRENT_LIST_DIR}/../external/d3d12/agility_sdk_lock.txt")
if(NOT EXISTS "${LOCK_FILE}")
    message(FATAL_ERROR "D3D12 SDK lock file missing: ${LOCK_FILE}")
endif()
file(STRINGS "${LOCK_FILE}" _lines)
set(_winsdk ""); set(_agility ""); set(_nupkg_sha512 ""); set(_dll_sha512 "")
foreach(_line IN LISTS _lines)
    if(_line MATCHES "^winsdk=(.+)$")        set(_winsdk "${CMAKE_MATCH_1}")
    elseif(_line MATCHES "^agility=(.+)$")   set(_agility "${CMAKE_MATCH_1}")
    elseif(_line MATCHES "^nupkg_sha512=(.+)$") set(_nupkg_sha512 "${CMAKE_MATCH_1}")
    elseif(_line MATCHES "^dll_sha512=(.+)$")   set(_dll_sha512 "${CMAKE_MATCH_1}")
    endif()
endforeach()
if(NOT _winsdk STREQUAL "10.0.26100.0")
    message(FATAL_ERROR "winsdk pin drift: '${_winsdk}' != 10.0.26100.0")
endif()
if(NOT _agility STREQUAL "1.616.0")
    message(FATAL_ERROR "agility pin drift: '${_agility}' != 1.616.0")
endif()
foreach(_h IN ITEMS _nupkg_sha512 _dll_sha512)
    if(NOT ${_h} MATCHES "^[0-9a-f]{128}$")
        message(FATAL_ERROR "lock hash malformed: ${_h}='${${_h}}'")
    endif()
endforeach()
# If the package was already fetched, verify the DLL hash honestly.
set(_dll "${CMAKE_CURRENT_LIST_DIR}/../external/d3d12/agility/build/native/bin/x64/D3D12AgilitySDK.dll")
if(EXISTS "${_dll}")
    file(SHA512 "${_dll}" _actual)
    if(NOT _actual STREQUAL _dll_sha512)
        message(FATAL_ERROR "D3D12AgilitySDK.dll hash mismatch: ${_actual}")
    endif()
endif()
message(STATUS "D3D12 SDK lock: winsdk=${_winsdk} agility=${_agility} hashes=ok")
```

```c
RHIDevice *rhi_device_create_ex(RHIBackend backend, void *window_native,
                                void *display_native, u32 w, u32 h,
                                RHIResult *out_result) {
    (void)window_native; (void)display_native; (void)w; (void)h;
    if (backend != RHI_BACKEND_D3D12) {
        if (out_result != NULL) *out_result = RHI_RESULT_INVALID_ARGUMENT;
        return NULL;
    }
    if (out_result != NULL) *out_result = RHI_RESULT_UNAVAILABLE;
    return NULL;
}
RHIDevice *rhi_device_create(RHIBackend backend, void *window_native,
                             void *display_native, u32 w, u32 h) {
```

```c
static HRESULT rhi_d3d12_pick_adapter(IDXGIFactory6 *factory, IDXGIAdapter1 **out) {
    IDXGIAdapter1 *best = NULL;
    SIZE_T best_memory = 0;
    UINT index = 0u;
    if (getenv("ENGINE_D3D12_WARP") != NULL) {
        IDXGIAdapter *warp = NULL;
        HRESULT hr = IDXGIFactory4_EnumWarpAdapter(factory, &IID_IDXGIAdapter, (void **)&warp);
        if (SUCCEEDED(hr)) { *out = (IDXGIAdapter1 *)warp; return S_OK; }
        return hr;
    }
    for (;;) {
        IDXGIAdapter1 *candidate = NULL;
        DXGI_ADAPTER_DESC1 desc;
        HRESULT hr = IDXGIFactory6_EnumAdapterByGpuPreference(
            factory, index++, DXGI_GPU_PREFERENCE_HIGH_PERFORMANCE,
            &IID_IDXGIAdapter1, (void **)&candidate);
        if (hr == DXGI_ERROR_NOT_FOUND) break;
        if (FAILED(hr)) break;
        if (SUCCEEDED(IDXGIAdapter1_GetDesc1(candidate, &desc)) &&
            (desc.Flags & DXGI_ADAPTER_FLAG_SOFTWARE) == 0u &&
            SUCCEEDED(D3D12CreateDevice((IUnknown *)candidate, D3D_FEATURE_LEVEL_12_0,
                                        &IID_ID3D12Device, NULL)) &&
            (best == NULL || desc.DedicatedVideoMemory > best_memory)) {
            if (best != NULL) IDXGIAdapter1_Release(best);
            best = candidate; best_memory = desc.DedicatedVideoMemory; candidate = NULL;
        }
        if (candidate != NULL) IDXGIAdapter1_Release(candidate);
    }
    if (best == NULL) return DXGI_ERROR_NOT_FOUND;
    *out = best;
    return S_OK;
}
```

```c
    ID3D12DeviceRemovedExtendedData1 *dred = NULL;
    D3D12_DRED_AUTO_BREADCRUMBS_OUTPUT1 crumbs;
    if (!ctx->dred_enabled) return;
    if (FAILED(ID3D12Device_QueryInterface(ctx->device,
            &IID_ID3D12DeviceRemovedExtendedData1, (void **)&dred))) return;

            node = node->pNext;
        }
    }

}
```

```c
#define RHI_D3D12_FENCE_TIMEOUT_MS 20000u

static RHIResult rhi_d3d12_wait_frame_slot(RHI_D3D12Context *ctx, UINT slot) {
    UINT64 target;
    HRESULT hr;
    if (ctx->device_lost) return RHI_RESULT_DEVICE_LOST;
    target = ctx->frame_fence[slot];
    if (target == 0u || ID3D12Fence_GetCompletedValue(ctx->fence) >= target)
        return RHI_RESULT_OK;
    hr = ID3D12Fence_SetEventOnCompletion(ctx->fence, target, ctx->fence_event);
    if (hr == DXGI_ERROR_DEVICE_REMOVED) return rhi_d3d12_note_device_lost(ctx);
    if (FAILED(hr)) return RHI_RESULT_SYNC_FAILED;
    if (WaitForSingleObject(ctx->fence_event, RHI_D3D12_FENCE_TIMEOUT_MS) != WAIT_OBJECT_0) {
        /* A fence unsignaled for 20 s mirrors the VK sticky-loss rule
         * (rhi.h:854-858): latch lost so callers wind down. */
        return rhi_d3d12_note_device_lost(ctx);
    }
    ctx->completed_fence = target;
    return RHI_RESULT_OK;
}
```

- **Back buffer 数量 = 3**。理由：flip model（`DXGI_SWAP_EFFECT_FLIP_DISCARD`）下 present engine 与 GPU 各可持有一帧，3 缓冲避免 CPU 在 `frame_fence` 等待上 stall；`rhi_frame_index` 的双槽语义独立于此——它索引的是 per-frame command allocator 环（2 槽），与 swapchain 缓冲数解耦。
- **present damage**：RHIPresentRect 本来就是 top-left 原点，与 `DXGI_PRESENT_PARAMETERS` 的 dirty rects 同约定——**不调用** `rhi_present_damage_to_bottom_left`（那是 GL/EGL 专用转换，rhi.h:440-445）。

```c
HRESULT rhi_d3d12_swapchain_create(RHI_D3D12Context *context,
                                   RHI_D3D12Swapchain *out, HWND hwnd,
                                   UINT width, UINT height) {
    DXGI_SWAP_CHAIN_DESC1 desc;
    IDXGISwapChain1 *sc1 = NULL;
    HRESULT hr;
    UINT i;
    if (context == NULL || out == NULL || hwnd == NULL || width == 0u || height == 0u)
        return E_INVALIDARG;
    ZeroMemory(out, sizeof(*out));
    ZeroMemory(&desc, sizeof(desc));
    desc.Width = width;
    desc.Height = height;
    desc.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
    desc.SampleDesc.Count = 1u;
    desc.BufferUsage = DXGI_USAGE_RENDER_TARGET_OUTPUT;
    desc.BufferCount = RHI_D3D12_BACKBUFFER_COUNT;
    desc.SwapEffect = DXGI_SWAP_EFFECT_FLIP_DISCARD;
    hr = IDXGIFactory6_CreateSwapChainForHwnd(context->factory,
        (IUnknown *)context->direct_queue, hwnd, &desc, NULL, NULL, &sc1);
    if (FAILED(hr)) return hr;
    hr = IDXGISwapChain1_QueryInterface(sc1, &IID_IDXGISwapChain4, (void **)&out->swapchain);
    IDXGISwapChain1_Release(sc1);
```

```c
static RHIResult rhi_d3d12_present(RHI_D3D12Context *ctx, RHI_D3D12Swapchain *sc,
                                   const RHIPresentRect *rects, UINT rect_count) {
    DXGI_PRESENT_PARAMETERS params;
    DXGI_PRESENT_PARAMETERS *pparams = NULL;
    HRESULT hr;
    if (ctx->device_lost) return RHI_RESULT_DEVICE_LOST;
    if (rects != NULL && rect_count > 0u) {
        /* RHIPresentRect is already top-left origin: direct memcpy-compatible
         * with RECT, no bottom-left conversion (that is the GL/EGL path). */
        ZeroMemory(&params, sizeof(params));
        params.DirtyRectsCount = rect_count;
        params.pDirtyRects = (RECT *)rects; /* same {x,y,w,h} i32 layout */
        pparams = &params;
    }
    hr = IDXGISwapChain1_Present1((IDXGISwapChain1 *)sc->swapchain,
                                  sc->vsync ? 1u : 0u,
                                  sc->vsync ? 0u : DXGI_PRESENT_ALLOW_TEARING,
                                  pparams);
    if (hr == DXGI_ERROR_DEVICE_REMOVED || hr == DXGI_ERROR_DEVICE_RESET)
        return rhi_d3d12_note_device_lost(ctx);
    if (hr == DXGI_STATUS_OCCLUDED) return RHI_RESULT_BUSY;
    if (FAILED(hr)) return RHI_RESULT_ERROR;
    sc->current_index = IDXGISwapChain3_GetCurrentBackBufferIndex((IDXGISwapChain3 *)sc->swapchain);
    return RHI_RESULT_OK;
}
```

```c
typedef struct RHI_D3D12DescriptorAlloc {
    ID3D12DescriptorHeap *heap;
    UINT increment;
    UINT capacity;
    UINT *free_slots;      /* stack of slot indices */
    UINT free_count;
    UINT64 *slot_fence;    /* per-slot retire fence; 0 = not in flight */
} RHI_D3D12DescriptorAlloc;

static UINT rhi_d3d12_descriptor_take(RHI_D3D12Context *ctx,
                                      RHI_D3D12DescriptorAlloc *alloc) {
    while (alloc->free_count > 0u) {
        UINT slot = alloc->free_slots[alloc->free_count - 1u];
        if (alloc->slot_fence[slot] != 0u &&
            ID3D12Fence_GetCompletedValue(ctx->fence) < alloc->slot_fence[slot])
            break; /* youngest free slot still GPU-busy; look no deeper */
        alloc->free_count--;
        return slot;
    }
    return UINT_MAX;
}

static void rhi_d3d12_descriptor_give_back(RHI_D3D12DescriptorAlloc *alloc,
                                           UINT slot, UINT64 retire_fence) {
    alloc->slot_fence[slot] = retire_fence;
    alloc->free_slots[alloc->free_count++] = slot;
}
```

```c
static ID3D12PipelineState *rhi_d3d12_create_graphics_pso(
        RHI_D3D12Context *ctx, ID3D12RootSignature *root_sig,
        const D3D12_SHADER_BYTECODE *vs, const D3D12_SHADER_BYTECODE *ps,
        const RHIPipelineDesc *desc) {
    D3D12_GRAPHICS_PIPELINE_STATE_DESC pso;
    UINT rt_count;
    ZeroMemory(&pso, sizeof(pso));
    pso.pRootSignature = root_sig;
    if (vs != NULL) pso.VS = *vs;
    if (ps != NULL) pso.PS = *ps;
    pso.RasterizerState.FillMode = desc->wireframe ? D3D12_FILL_MODE_WIREFRAME
                                                   : D3D12_FILL_MODE_SOLID;
    pso.RasterizerState.CullMode = desc->disable_culling ? D3D12_CULL_MODE_NONE
                                                         : D3D12_CULL_MODE_BACK;
    pso.DepthStencilState.DepthEnable = TRUE;
    pso.DepthStencilState.DepthFunc = desc->depth_compare_lequal
        ? D3D12_COMPARISON_FUNC_LESS_EQUAL : D3D12_COMPARISON_FUNC_LESS;
    pso.DepthStencilState.DepthWriteMask = desc->depth_write_disable
        ? D3D12_DEPTH_WRITE_MASK_ZERO : D3D12_DEPTH_WRITE_MASK_ALL;
    pso.BlendState.RenderTarget[0].BlendEnable = desc->alpha_blend ? TRUE : FALSE;
    if (desc->alpha_blend) {
        pso.BlendState.RenderTarget[0].SrcBlend = D3D12_BLEND_SRC_ALPHA;
        pso.BlendState.RenderTarget[0].DestBlend = D3D12_BLEND_INV_SRC_ALPHA;
        pso.BlendState.RenderTarget[0].BlendOp = D3D12_BLEND_OP_ADD;
    }
    rt_count = desc->mrt_attachment_count > 1u ? desc->mrt_attachment_count : 1u;
    if (desc->is_shadow_depth) rt_count = 0u;
    pso.NumRenderTargets = rt_count;
    if (rt_count > 0u) {
        UINT i;
        for (i = 0u; i < rt_count; ++i) {

                ? desc->mrt_formats[i] : desc->color_format;
            pso.RTVFormats[i] = rhi_d3d12_format(f);
        }
    }
    pso.DSVFormat = DXGI_FORMAT_D32_FLOAT;
    pso.SampleDesc.Count = desc->sample_count == 0u ? 1u : desc->sample_count;
    pso.SampleMask = UINT_MAX;
    pso.PrimitiveTopologyType = desc->point_list
        ? D3D12_PRIMITIVE_TOPOLOGY_TYPE_POINT : D3D12_PRIMITIVE_TOPOLOGY_TYPE_TRIANGLE;
    ID3D12PipelineState *result = NULL;
```
